# كتالوج المواقع — 61 موقعًا برصيد مجاني

> **تاريخ التحقق:** 8 نوفمبر 2026. الأرقام تتغير شهريًا؛ كل صف يحمل درجة ثقة: **ع** = منشور رسميًا، **م** = متفق عليه من عدة مصادر، **ض** = غير منشور/متغيّر إقليميًا.
> النسخة الآلية (المصدر الوحيد للحقيقة): [`catalog/sites.json`](../catalog/sites.json). المسار: `و` = أتمتة متصفح، `ب` = API، `و+ب` = الاثنان.

## كيف تقرأ الجدول

- **المجاني**: ما يُمنح فعليًا، لا ما يُعلن عنه. «~» يعني تقديري.
- **الدورة**: `يوم` = يتجدد كل 24 ساعة ولا يُرحَّل، `شهر` = حصة شهرية، `مرة` = تسجيل فقط.
- **المسار**: `و` يعني أن الواجهة لا تكشف API نظيفًا، فالحل أتمتة DOM أو HAR→API.
- **حدود المجاني**: الدقة/المدة/العلامة المائية/الحقوق. العلامة المائية شبه مؤكدة في كل مجاني الفيديو.

## الاستراتيجية: شلال (Waterfall) لا «موقع واحد»

```
لقطة فيديو:
  1. Dreamina (120/يوم)      ← الأرخص لكل ثانية
  2. Hailuo (~3 مقاطع)       ← جودة أعلى
  3. Kling (66/يوم)          ← أفضل حركة
  4. PixVerse (540p)         ← احتياطي
  5. Luma / Vidu             ← آخر خيار
صورة:
  1. Krea → 2. Leonardo → 3. Pollinations → 4. Bing
صوت:
  1. Kokoro محلي → 2. ElevenLabs → 3. TTSMaker
موسيقى:
  1. مكتبة محلية → 2. Suno → 3. Stable Audio
```

هذا هو الشلال الذي ينفّذه `CapabilityRouter` تلقائيًا عند نفاد الحصة أو فتح قاطع الدائرة.

## ما استُبعد ولماذا

- **Kaiber:** لا خطة مجانية ولا API عام.
- **Veed / Lumen5:** لا API عام موثّق؛ أتمتة الواجهة ممكنة نظريًا لكن غير موثوقة.
- **Sora:** أُغلق تطبيق Sora في أبريل 2026 وأُزيلت نماذج الفيديو من الـAPI في سبتمبر 2026 — لا تعتمد عليه.
- **PlayHT:** أُغلق.
- **Udio كمصدر ملفات:** التنزيل معطّل على كل الخطط؛ يصلح كمرجع لا كإنتاج.
