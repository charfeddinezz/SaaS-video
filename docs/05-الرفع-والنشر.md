# الرفع والنشر

> الهدف: نشر فيديو واحد يوميًا على الأقل، بلا رفع مزدوج، بلا حظر، وبميتاداتا تجلب النقر.

---

## 1. يوتيوب: الحقائق التي تحكم التصميم

| القيد | القيمة | الأثر |
| --- | --- | --- |
| مدة Shorts | ≤ 3 دقائق (عمودي) | خط الأنابيب يستهدف 35–55 ثانية |
| نسبة الأبعاد | 9:16 | `1080×1920` إلزامي |
| العنوان | ≤ 100 حرف | تحقق قبل الرفع (منفّذ) |
| الوصف | ≤ 5000 حرف | تحقق (منفّذ) |
| التاجات | ≤ 500 حرف إجمالًا | تحقق (منفّذ) |
| الصورة المصغّرة | ≤ 2MB، 1280×720 | تُولَّد من إطار + نص |
| حصة Data API | 10,000 وحدة/يوم | الرفع = 1600 → ~6 رفعات/يوم |
| فيديو API غير مُراجَع | يُجبَر على `private` | لذلك نستخدم المتصفح للنشر العام |

**قرار:** المتصفح هو المسار الأساسي للنشر العام؛ Data API احتياطي للتحليلات لا للرفع.

---

## 2. المسار الكامل

```
final.mp4 (1080×1920, −14 LUFS)
   │
   ├── فحص قبول: مدة، أبعاد، صوت، صورة مصغّرة، عنوان
   ├── ميتاداتا: عنوان + وصف + تاجات + hashtags
   ├── idempotency: sha256(account|file_hash|title)
   ├── sau youtube upload-video --visibility private
   ├── تحقق: هل ظهر الفيديو في القناة؟
   ├── جدولة: تحويل إلى public في وقت الذروة
   └── تسجيل: video_id, url, وقت النشر, snapshot للأداء
```

الرفع كـ`private` أولًا ثم التحويل يمنحك فرصة أخيرة للفحص، ويمنع ظهور فيديو معطوب.

---

## 3. التكامل مع `social-auto-upload`

```bash
# مرة واحدة لكل قناة
sau youtube login --account main
sau youtube check --account main

# كل فيديو
sau youtube upload-video \
  --account main \
  --file out/final.mp4 \
  --title "3 أخطاء تقتل فيديوهاتك القصيرة" \
  --desc "الوصف…" \
  --tags shorts,ai,contentcreation \
  --visibility private
```

في النواة:

```ts
const outcome = await publisher.uploadYouTube({
  account: process.env.YT_ACCOUNT ?? 'main',
  file: 'out/final.mp4',
  title,
  description,
  tags,
  visibility: 'private',
});

if (!outcome.ok) {
  // لا تعِد المحاولة فورًا: افحص إن كان الفيديو قد رُفع فعلًا
  await reconcile(account, outcome.idempotencyKey);
}
```

**حالة «مجهول»:** إن انتهت المهلة بلا استجابة، لا ترفع مرة أخرى. افحص آخر فيديوهات القناة؛ إن وُجد مطابق للعنوان/الوقت، سجّله وانتقل.

### تعدّد القنوات
- حساب `sau` واحد لكل قناة، وملف تعريف متصفح مستقل.
- لا تشارك نفس ملف التعريف بين قناتين؛ يزيد احتمال الحظر.
- بروكسي ثابت لكل قناة إن كانت القنوات في دول مختلفة.

## 4. الميتاداتا التي تعمل

### العنوان (≤ 100)
```
[رقم/تناقض] + [فائدة محددة] + [جمهور]
مثال: "3 أخطاء تجعل فيديوك القصير يموت في أول 3 ثوان"
```

### الوصف
```
سطر أول (يظهر قبل "المزيد"): وعد الفيديو.
سطران: ماذا سيتعلم المشاهد.
CTA: احفظ الفيديو / تابع للمزيد.
Hashtags: 3–5 فقط (#shorts #ai #…)
إفصاح: "صُنع بمساعدة الذكاء الاصطناعي" عند استخدام أصوات/صور اصطناعية واقعية.
```

### التاجات
5–8 وسوم، مزيج بين واسع (`shorts`) وضيق (`ai video editing`). لا تحشُ.

### الصورة المصغّرة
- إطار من الفيديو + 3–5 كلمات كبيرة + تباين عالٍ.
- لا تستخدم صورة مصغّرة مضلّلة؛ سياسة يوتيوب تعاقب على ذلك.

---

## 5. الجدولة

| العنصر | القاعدة |
| --- | --- |
| عدد النشر | 1–2/يوم/قناة، لا أكثر |
| الفجوة | ≥ 18 ساعة بين نشرين |
| التوقيت | 11:00–13:00 و17:00–20:00 بتوقيت الجمهور |
| الأسبوع الأول | 5 فيديوهات لقياس الاستجابة |
| بعد ذلك | حسب الاحتفاظ لا حسب الشعور |

الجدولة تُخزَّن في قاعدة البيانات، والمُشغّل يرفع `private` ثم يحوّل `public`؛ لا تعتمد على `--publish-at` وحده لأنه يفشل إن كانت الجلسة منتهية.

## 6. منصات أخرى عبر نفس المستودع

| المنصة | الأمر/الوحدة | ملاحظة |
| --- | --- | --- |
| TikTok | `tiktok_uploader` | عمودي، 1080×1920 |
| Instagram Reels | `instagram_uploader` | Reels + كاروسيل |
| Facebook / Page | `facebook_uploader` | فيديو + جدولة |
| Douyin / Bilibili / XHS / Kuaishou / WeChat / Baijiahao | وحدات `sau` | واجهات صينية؛ تحتاج حسابًا محليًا |

القاعدة: **محتوى مختلف لكل منصة**، لا نفس الملف بنفس النص. يوتيوب يفضّل عنوانًا وصفيًا، وتيك توك يفضّل Hook نصيًا على الشاشة.

## 7. حلقة التغذية الراجعة

```
YouTube Analytics API (أو scraping يدوي) كل 24 ساعة:
  views, impressions, CTR, avg_view_duration, retention_3s, likes, comments
        │
        ▼
  جدول performance(video_id, pattern_id, metrics)
        │
        ├── Thompson Sampling يحدّث أوزان الأنماط
        ├── تقرير أسبوعي: أفضل/أسوأ 5 مع السبب
        └── مكتبة البرومبتات: ترقية الصيغ الفائزة
```

**عتبة العينة:** لا تُغيّر النمط قبل 30 ظهورًا أو 7 أيام، أيهما أطول.

## 8. الامتثال على يوتيوب

1. **المحتوى المعاد استخدامه:** يوتيوب يمنع المحتوى «غير الأصيل»؛ لا ترفع تجميعًا حرفيًا لمقاطع الآخرين.
2. **الإفصاح عن المحتوى الاصطناعي:** مطلوب عند واقعية عالية (أصوات/وجوه). ضع سطرًا في الوصف.
3. **الموسيقى:** موسيقى Suno/Udio المجانية **بلا حقوق تجارية**؛ استخدم مكتبة CC0 أو اشتراكًا قبل تحقيق الدخل.
4. **العلامات المائية:** فيديو Kling/Hailuo المجاني يحمل علامة؛ لا تحاول إزالتها.
5. **التضليل:** لا تستخدم صورًا/أصوات شخصيات حقيقية بلا إذن.
6. **الحسابات:** حساب واحد لكل قناة، بلا تسجيل دخول آلي مكثّف من IPs متغيرة.

---

## 9. قائمة تحقق قبل كل نشر

- [ ] 1080×1920، 30fps، H.264، AAC 192kbps.
- [ ] المدة 20–58 ثانية (Shorts).
- [ ] الصوت −14 LUFS، بلا clipping.
- [ ] الكابشن متزامن، بلا أخطاء إملائية.
- [ ] لا علامة مائية لمزوّد غير مرخّص.
- [ ] العنوان ≤ 100 والوصف ≤ 5000 والتاجات ≤ 500.
- [ ] صورة مصغّرة ≤ 2MB ومناسبة.
- [ ] مفتاح idempotency جديد (لا نشر مزدوج).
- [ ] الجلسة صالحة (`sau youtube check`).
- [ ] نسخة احتياطية من الملف والميتاداتا في مخزن الأصول.
