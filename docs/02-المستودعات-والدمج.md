# المستودعات والدمج

> القاعدة الحاكمة: **لا نُدمج ثلاثين مستودعًا في مستودعنا.** نلفّها خلف ثلاثة عقود ونستبدلها متى شئنا.

---

## 1. قرار الدمج

| ما نبنيه بأنفسنا | ما نلفّه (wrap) | ما نتركه |
| --- | --- | --- |
| الموجّه، دفتر الرصيد، خط الأنابيب، الحوكمة | WebChat2API (LLM) | نسخ كود المستودعات داخل `src/` |
| عقود `SiteAdapter` / `Publisher` | social-auto-upload (نشر) | تشغيل 30 SDK دفعة واحدة |
| طبقة الجلسات والمراقبة | Playwright / browser-use | بناء متصفح خاص |
| البرومبت DSL والبوابات | FFmpeg / Kokoro / Whisper | إعادة كتابة محرر فيديو |

السبب: كل مستودع خارجي يتغيّر أو يتوقف؛ العقد الداخلي الثابت هو ما يجعل المنصة تعيش أطول من مزوّديها.

class KlingAdapter implements SiteAdapter<ShotRequest, ClipResult> {

  async collect(result, dest) { return downloadAll(result.urls, dest); }

## 4. التحكم في واجهات الذكاء الاصطناعي — WebChat2API

### 4.1 ما هو

`zqbxdev/webchat2api` (Python/FastAPI + Next.js، MIT، ~363 نجمة): وسيط يحوّل جلسات **ChatGPT Web / Grok Web / Gemini Web** إلى واجهة متوافقة مع OpenAI وAnthropic. يشمل:

- `POST /v1/chat/completions` و`/v1/responses` و`/v1/messages`.
- `POST /v1/images/generations` و`/v1/images/edits` (نماذج `gpt-image-2`, `grok-imagine-image`, `grok-imagine-image-edit`).
- إدارة مجموعة حسابات (account pool) واختيار الحساب حسب tier والقدرات، تجاوز الحساب الفاشل داخل نفس المهمة.
- لوحة ويب لإدارة الحسابات والمفاتيح والبروكسي والسجلات.
- Docker: `docker run -p 83:83 -v $(pwd)/data:/app/data webchat2api`.

### 4.2 كيف نستخدمه

```ts
import { WebChat2Api } from './src/providers/webchat2api.js';

const llm = new WebChat2Api({
  baseUrl: process.env.WEBCHAT2API_URL ?? 'http://127.0.0.1:83',
  apiKey: process.env.WEBCHAT2API_KEY!,
});

const brief = await llm.json<Brief>([
  { role: 'user', content: `اكتب موجز فيديو قصير عن: ${topic}` },
]);
```

النواة تحتوي بالفعل هذا العميل (`src/providers/webchat2api.ts`) مع `chat`, `image`, `json`, و`extractJson` المتسامح مع أسوار الماركداون.

### 4.3 التحذيرات المنقولة من المستودع نفسه

- المشروع نفسه يعلن: «للبحث الشخصي والتقني غير التجاري»، ويحذّر من الحظر وإساءة الاستخدام.
- Cloudflare/WAF/الحصص تتغير؛ `FlareSolverr` و`Browser Bridge` «أفضل جهد» وليست ضمانًا.
- بعض المزوّدين (مثل Z.ai) محجوبون بكابتشا أمامية، وليس مجرد JWT.
- **لا تعتمد عليه للامتثال**: هو أداة استكشاف. للإنتاج، Ollama محلي أو API رسمي.

### 4.4 عائلة مشابهة

| المستودع | التغطية | ملاحظة |
| --- | --- | --- |
| `MOSSVENC/WebChat2Api` | DeepSeek Web فقط | يحل PoW (WASM+wasmtime)، مصادقة مزدوجة، SSE |
| `Zeeeepa/Webchat2Api` | docs لمزوّدين (zai, …) | مرجع جيد لشكل `docs/providers/*` |
| `browser-use/browser-use` | أتمتة وكيل للمتصفح | بديل لطبقة الجلسات عند التعقيد |
| `Skyvern` | أتمتة نماذج الويب بالرؤية | مفيد للمواقع ذات DOM متغيّر |

## 5. النشر — social-auto-upload

> **تصحيح مهم:** لم أجد مستودعًا باسم `social-auto-upload-international` بالضبط. المستودع القانوني هو **`dreammis/social-auto-upload`** (MIT، ~9k نجمة) وهو يشمل TikTok وYouTube وInstagram/Facebook وغيرها، مع CLI `sau`. أقدم نسخة «دولية» هي فروع مثل `BudongJW/social-auto-upload` (TikTok + YouTube Shorts بـPlaywright). استخدم الأصل وحدّثه.

| القدرة | الأمر/الواجهة |
| --- | --- |
| تسجيل الدخول | `sau youtube login --account <name>` (تفاعلي في المتصفح) |
| فحص الحساب | `sau youtube check --account <name>` |
| رفع فيديو | `sau youtube upload-video --account <name> --file f.mp4 --title "..." --desc "..." --tags a,b --playlist "..." --visibility public` |
| بقية المنصات | Douyin, Bilibili, Xiaohongshu, Kuaishou, WeChat Channels, Baijiahao, TikTok, Instagram, Facebook |

**لماذا المتصفح:** المستودع نفسه يشرح أن YouTube Data API غير المُراجَع يجبر الفيديو على `private`، لذا يعتمد الأتمتة للنشر العام.

**التكامل في نواتنا:**

```ts
import { SocialAutoUpload } from './src/upload/social-auto-upload.js';

const publisher = new SocialAutoUpload({
  async run(cmd, args) {
    // execa/spawn فعلي في الإنتاج
    return { code: 0, stdout: `https://youtu.be/${id}`, stderr: '' };
  },
});

await publisher.uploadYouTube({
  account: 'main',
  file: 'out/final.mp4',
  title: '3 أخطاء تقتل فيديوهاتك القصيرة #shorts',
  description: '…',
  tags: ['shorts', 'ai', 'content'],
  visibility: 'public',
});
```

النواة تتحقق من: العنوان 1–100، الوصف ≤ 5000، التاجات ≤ 500 حرف، وتبني مفتاح idempotency `account:file:title` لمنع الرفع المزدوج.

## 8. الترخيص والمخاطر

| البند | الحالة |

| WebChat2API | MIT، لكن إعلان صريح «غير تجاري» ومسؤولية الحظر على المستخدم |
