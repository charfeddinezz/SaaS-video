# ReelForge — مصنع الفيديوهات القصيرة المستقل

منصة تُدار بالوكلاء: من فكرة → سيناريو → لوحة لقطات → صور/مقاطع → تعليق صوتي وموسيقى → مونتاج → فحص جودة → نشر على يوتيوب — بالاعتماد على **الأرصدة المجانية اليومية** في واجهات الويب، لا على مفاتيح API مدفوعة.

> **حالة المشروع:** هذه الحزمة تحتوي **الخطة الكاملة + كتالوج 61 موقعًا (JSON قابل للقراءة آليًا) + نواة برمجية تعمل ومُختبرة** (الموجّه، دفتر الرصيد، خط الأنابيب، الحارس، جسر WebChat2API، ناشر social-auto-upload). لم تُبنَ بعد 61 مهايئًا (adapter) لكل موقع — هذا هو العمل الهندسي المتبقي، وقد وُثّق كيف يُبنى كل واحد منها في `docs/04`.

## تشغيل سريع

```bash
npm install
npm run build      # يحوّل src/ إلى dist/
npm run catalog    # يتحقق من الكتالوج (≥ 50 موقعًا، معرفات فريدة، قدرات صحيحة)
npm test           # 10 اختبارات: الرصيد، التوجيه، القواطع، الأنابيب، البوابات، الرفع
```

## المبادئ التي بُني عليها التصميم

1. **القدرة أولًا، المزوّد ثانيًا.** الطلب يقول `text2video`، والموجّه يختار المزوّد حسب الجودة والرصيد والصحة — لا كود مكتوب لكل موقع داخل المسار الرئيسي.
2. **الرصيد مورد نادر.** دفتر رصيد يمنع حرق اليوم كله في أول عشر دقائق، ويوزّع الحصة على مهام اليوم.
3. **كل شيء قابل للاستئناف.** كل مرحلة في خط الأنابيب لها checkpoint؛ إعادة التشغيل لا تعيد إنفاق الرصيد.
4. **الفشل متوقع.** قاطع دائرة لكل مزوّد، ومهايئ احتياطي، وتبديل تلقائي عند فشل المحدّد.
5. **الإنسان عند الحدود فقط.** تسجيل الدخول والكابتشا والتحقق بخطوتين تُمرَّر إلى طابور بشري؛ الروبوت لا يحلّها.
6. **الشفافية.** الكتالوج يحمل `confidence` وتاريخ التحقق؛ الأرقام غير المنشورة تُعلَّم `low`.
7. **الامتثال ليس خيارًا.** أتمتة واجهة مستخدم قد تخالف شروط الخدمة وقد تؤدي لحظر الحساب. المنصة تفصل «المسار الرسمي» عن «المسار التجريبي»، وتضع علامة مخاطر، وتمنع المخاطر العالية افتراضيًا (`allowHighRisk`).

## ملاحظة قانونية

الأرصدة المجانية في هذه المواقع مخصّصة للاستخدام البشري، وأتمتتها قد تخالف شروط الخدمة، وقد تُسقط الحساب أو تُلغي الحقوق التجارية للمخرجات. استخدم الكتالوج لتقليل التكلفة في **الاستكشاف والنماذج الأولية**، وانتقل إلى API رسمي أو نموذج مفتوح مستضاف محليًا عند الإنتاج التجاري. راجع `docs/00` قسم «المخاطر» و`docs/04` قسم «الامتثال».
